## Three cards

**Card 1: prospect-map**

Count every business in your niche and geography from public records. Every row carries its owner, its status and the evidence behind it, dated.

Command line under the card: `/prospect-map "<niche>" "<geography>"`

**Card 2: discovery-sheet**

Turn a call transcript into notes you can prove: every number, every quote, the ICP in their words, plus the next-call sheet.

Command line under the card: `/discovery-sheet <transcript> "<prospect>"`

**Card 3: one-pager**

One personalised page per prospect, built from their own numbers, in your voice, with the three-line email that carries it. Sourced facts only.

Command line under the card: `/one-pager <research-file> [voice-profile]`

## Install

**Section heading**

Install

**Lead line**

Two commands inside Claude Code. No API keys, no accounts, nothing to pay for.

**Code block** (with a copy button)

```
/plugin marketplace add aaxelera/leadgen-skills
/plugin install leadgen-skills@aaxelera-leadgen-skills
```

**Under the block**

Needs Claude Code and Python 3.8 or newer for the map skill's helper scripts. Everything else is built in. MIT licensed. Source on GitHub.
